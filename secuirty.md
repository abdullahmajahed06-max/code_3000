# Security 

This repository is mainly for me and my instructor to use for class assignments.

The security risk is pretty low because the repo only contains schoolwork and does not include private information, passwords, or API keys.

To keep the repo secure, I make sure not to upload any sensitive information and only allow authorized users to make changes. Since this is a small class project, I do not think extra security features like CODEOWNERS or pull request rules are necessary.
